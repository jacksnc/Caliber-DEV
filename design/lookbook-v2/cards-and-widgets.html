02 / AT A GLANCE

Useful at every size.

One Fuel widget grows from a single daily check to a compact meal breakdown. Choose a locked-screen preview to see the privacy state.

Preview device locked Visual prototype. Native WidgetKit privacy redaction is not implemented here.

Privacy direction: mark nutrition content as sensitive for system-managed Lock Screen redaction. Keep Stack details and body photos out of widget snapshots. Neutral shortcut content remains useful when the numbers are hidden.

03 / BEHAVIOR + SAFETY

A clear interaction contract.

01 · Keep gestures local

Only the nutrition summary card swipes. Meal rows keep their existing native actions, so a gesture on a food never changes the metric page.

02 · Keep arrows visible

Previous/Next buttons and page labels provide an alternative to swiping, with a full spoken metric name for VoiceOver.

03 · Respect reduced motion

Swap content without a sliding animation when Reduce Motion is on. There is no autoplay.

04 · Widgets stay glanceable

Widgets open the matching Diary destination. A widget is a read-only snapshot until a separate interaction is designed and tested.

Scope: original visual concept and interactive HTML preview, using synthetic values from the existing sample diary. No WidgetKit target, shared data container, App Group, entitlement, account data, or native card swipe is enabled by this lookbook.
